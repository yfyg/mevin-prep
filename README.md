# מוכנים למבין 🌟 - אתר תרגול למוח לילדים

אתר תרגול חינמי לילדים בכיתות ד'-ו', בנוי סביב ארבעה תחומי חשיבה מרכזיים:
חשיבה מילולית, חשיבה כמותית (חשבון), חשיבה צורנית, וסדרות חשבוניות.

הכל כאן הוא **HTML, CSS ו-JavaScript רגילים** - בלי צורך בשרת, בסיס נתונים
או ידע בתכנות כדי להריץ את זה. אפשר לפרסם את האתר בחינם תוך כמה דקות.

## הערה חשובה על מקור השאלות וזכויות יוצרים

השאלות באתר הן **מקוריות** - הן נכתבו בהשראת הסגנון, הנושאים ורמת הקושי
שמצאתי בחוברות התרגול ששלחת (חומרים של "מכון נועם" ואחרים), אך הן אינן
העתקה של השאלות עצמן. חוברות כאלה הן חומר לימוד מסחרי המסומן "כל הזכויות
שמורות", ולכן העתקה מילולית שלהן לאתר שיהיה נגיש לכולם ברשת עלולה להפר
זכויות יוצרים. כדי לשמור על האתר בטוח מבחינה משפטית ועדיין נאמן לסגנון
ולרמת הקושי האמיתיים, כל שאלה כאן נכתבה מחדש עם מספרים, מילים ודוגמאות
שונות - אותו "טעם", בלי להעתיק.

## מבנה הקבצים

```
mevin-prep/
├── index.html      - דף הבית
├── practice.html   - דף התרגול (בחירת קטגוריה + מבחן + תוצאות)
├── style.css       - כל העיצוב
├── script.js       - כל הלוגיקה (ניקוד, זיכרון, שמירת התקדמות)
├── questions.js    - מאגר השאלות - כאן מוסיפים שאלות חדשות
└── README.md       - הקובץ הזה
```

## איך מוסיפים שאלות חדשות (כשה-PDF יגיע)

כל השאלות נמצאות בקובץ **questions.js**. בראש הקובץ יש הסבר מפורט, אבל בקצרה:

1. פותחים את `questions.js` בכל עורך טקסט (אפשר אפילו ב-Notepad, אבל מומלץ
   VS Code שהוא חינמי).
2. מוצאים את הקטגוריה המתאימה: `verbal` (מילולי), `quantitative` (כמותי),
   `figural` (צורני) או `sequences` (סדרות חשבוניות).
3. מעתיקים שאלה קיימת מאותה קטגוריה כתבנית, ומחליפים את התוכן שלה.
4. שומרים את הקובץ - זהו, השאלה החדשה תופיע באתר באופן אוטומטי.

אין הגבלה על כמות השאלות, ואפשר גם ליצור קטגוריה חדשה לגמרי אם יתגלה צורך -
פשוט תשלחי לי (לקלוד) חומר נוסף ואבנה סביבו שאלות מקוריות באותו סגנון.

## איך מפרסמים את האתר בחינם (בלי ידע טכני)

יש כמה אפשרויות. הכי מהיר וקל - **Netlify Drop**.

### אפשרות 1: Netlify Drop (הכי מהיר, מומלץ להתחלה)

1. נכנסים לכתובת: **https://app.netlify.com/drop**
2. גוררים את כל תיקיית `mevin-prep` (עם כל הקבצים שבפנים) ישירות לתוך העמוד
   בדפדפן.
3. תוך כמה שניות תקבלו קישור חי (למשל `random-name-123.netlify.app`) -
   האתר כבר באוויר וכל אחד יכול להיכנס אליו!
4. אם רוצים כתובת קבועה ויכולת לעדכן את האתר בעתיד, כדאי ליצור חשבון חינמי
   ב-Netlify (לחיצה על "Sign up" למעלה) ואז לחבר את האתר לחשבון - כך גם
   שומרים אותו לצמיתות וגם אפשר להחליף לו שם.

### אפשרות 2: GitHub Pages (קבוע יותר, דורש הרשמה חד-פעמית)

1. פותחים חשבון חינמי ב-**github.com** (אם אין כבר).
2. יוצרים repository (מאגר) חדש - למשל בשם `mevin-prep`.
3. מעלים אליו את כל הקבצים מהתיקייה (יש כפתור "Add file" -> "Upload files"
   באתר של GitHub - גוררים את הקבצים פנימה).
4. נכנסים ל-Settings של ה-repository -> לשונית Pages -> תחת "Branch" בוחרים
   `main` ולוחצים Save.
5. אחרי דקה-שתיים האתר יהיה זמין בכתובת כמו:
   `https://<שם-המשתמש-שלך>.github.io/mevin-prep/`

היתרון של GitHub Pages: כל פעם שרוצים לעדכן שאלות (לערוך את questions.js),
מעלים את הקובץ המעודכן דרך אותו כפתור "Add file" -> "Upload files", והאתר
מתעדכן אוטומטית תוך דקה.

## מה שכבר קיים באתר

- **4 קטגוריות תרגול** (מילולי, כמותי, צורני, סדרות חשבוניות) עם 300 שאלות
  מקוריות ברמת כיתות ד'-ו' (85 מילולי, 85 כמותי, 65 צורני עם גרפיקה מצוירת
  (SVG) בסגנון מטריצות אמיתי, 65 סדרות), כולל הסבר לכל תשובה.
- כל סבב תרגול הוא **5 שאלות בלבד** (20 בתרגול מעורב) כדי שלא יהיה עומס
  על התלמיד/ה, עם ציון ומשוב מעודד בסיום.
- **תרגול מעורב** ששואב שאלות מכל הקטגוריות יחד - כמו במבחן האמיתי.
- **מסך תוצאות** עם ניקוד, משוב מעודד, וסקירה של כל שאלה ושאלה.
- **שמירת התקדמות** בדפדפן (localStorage) - כך שרואים בדף הבית כמה סבבי
  תרגול נעשו, אחוז ההצלחה הממוצע והתוצאה הכי טובה.

## מה כדאי לעשות בהמשך

1. אם יש עוד חומר (PDF נוסף, או הערות על מה שהיה קשה/קל מדי) - תשלחי לי
   ואמשיך להרחיב את מאגר השאלות באותו סגנון.
2. אם רוצים, אפשר להוסיף מצב "מבחן מתוזמן" (עם שעון עצר לכל חלק, כמו במבחן
   האמיתי) - זו תוספת קלה יחסית לבנייה.
3. אפשר גם להוסיף רמת קושי (קל/בינוני/מאתגר) בתוך כל קטגוריה, אם ירצו לדרג
   את השאלות בהדרגה.
